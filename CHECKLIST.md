### НЕ загружать:
```
❌ /node_modules/     (установятся автоматически)
❌ /.next/            (создастся при сборке)
❌ .env.local         (секреты - только через UI хостинга)
❌ *.bat              (bat-файлы Windows)
❌ desktop.ini        (системные файлы Windows)
```

## Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Build failed | Проверь логи сборки, возможно не хватает зависимостей |
| 500 Internal Error | Проверь переменные окружения |
| Не могу войти | Проверь `ADMIN_USERNAME` и `ADMIN_PASSWORD` |
| Комментарии не сохраняются | Нормально для serverless, нужна БД |
| Медленно грузится | Оптимизируй изображения или выбери другой регион |
